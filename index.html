ABOUT PROJECT S:

Software shaped by survey methodology.

Project S: is an umbrella for independent software tools supporting survey research. The project emphasizes transparent workflows, methodological quality and practical usability in research environments.

DEVS is the first tool developed within Project S:. Additional tools may be added as the project evolves.
